# WorkBuddy 栏目与指标说明

## 栏目定义

- 推荐主栏目名：`WorkBuddy 真实工作现场`。
- 保留搜索与记忆标签：`WorkBuddy 百问百答`。
- 固定子系列：`新手开箱`、`现场实操`、`翻车诊所`、`职场交付`、`一人公司`、`内容复用`、`学员前后`。
- 内容单位不是一个问号，而是一个可验证的工作命题：谁在什么场景卡住、WorkBuddy 如何介入、得到什么结果、哪里仍需人工判断、下一步是什么。

## 日更原则

日更指每天有一个对外内容单元，不等于每天从零生产。每周选择3个母题，各做一份5—12分钟屏幕实操、逐字稿、关键截图和结果文件，再拆成短视频、卡片、短图文、公众号长文和可选长视频。3个母题可覆盖一周的多平台更新。

## 转化层级

1. 免费内容：解决一个原子问题，给出一个可验证结果。
2. 互动资产：用关键词领取清单、模板、任务路由图或自检表。
3. 信任场：进入直播看完整任务，或提交自己的真实工作场景。
4. 课程：把分散技巧串成“工作现场 + 知识库 + 专家 + Skill + 真实作品”的个人AI助手系统。

## 首轮指标

- 主指标1：内容激活率 = 发布后7天内完成该内容唯一CTA的去重人数 / 可获得的平台阅读或播放人数。各平台分别计算，不直接混合。
- 主指标2：有效意向数 = 明确描述自己的工作任务、报名直播或询问课程适配的去重人数；按内容编号归因。
- 主指标3：意向成交率 = 发布后14天内可归因购买人数 / 有效意向人数。
- 驱动指标：短视频完播或平均观看、图文收藏、关键词回复、直播到场。
- 护栏：每个母题总制作时长、取消关注/负反馈、事实错误或隐私问题。

前14天不设行业拍脑袋目标，先建立自己的中位数基线。第15天起：高于同形式中位数1.5倍或带来至少2个有效意向的题加做；连续3次低于0.7倍且无高质量反馈的表达暂停；模板稳定后把单个母题总制作时间控制在3小时左右作为内部效率目标。
