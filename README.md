## 快速入口

- [`INDEX.md`](INDEX.md)：100 篇文章总目录

- [`analysis/`](analysis/)：主题分布、标题钩子、系列演进、候选选题及分析笔记本

## 推荐使用方式

1. 按篇阅读：从 [`INDEX.md`](INDEX.md) 进入，再打开 `articles/` 中对应文章。
2. 全文搜索：直接在 GitHub 仓库中搜索关键词，或下载后搜索 `articles/`。
3. 数据分析：优先使用 `data/article_index.csv`、`data/article_index.json` 或 `data/article_full.jsonl`。
4. 查看研究结论：打开 `reports/WorkBuddy百问百答_100篇参考分析.html`。
