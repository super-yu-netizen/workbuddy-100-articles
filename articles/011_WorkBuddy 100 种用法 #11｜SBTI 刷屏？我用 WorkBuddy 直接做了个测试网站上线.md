## 正文

4月9日，全网突然被 SBTI 人格测试 刷屏。
微博热搜、朋友圈、微信群全在晒结果：「我是死者·吗喽」「你是狗屎人吗」「ATM‑er 报到」。

我点进原版想测一测，结果网站直接被流量挤崩。
既然这么火，我干脆自己用 WorkBuddy，从零搭了一个稳定可访问的版本。

一、什么是 SBTI？

SBTI 全称 Silly Big Personality Test，傻大个儿人格测试。
以 MBTI 为框架恶搞改编，把 16 型人格变成 27 种扎心自嘲标签：

死者、吗喽、狗屎人、草者、ATM‑er、幽灵、机器人……

没有心理学依据，纯娱乐玩梗。
但年轻人疯狂转发，因为每一句都像在说自己的真实精神状态。

二、我用 WorkBuddy 做了什么？（全程 4 步）

我只负责提需求，剩下全部交给 AI。

第一步：搜集素材（AI 5 秒搞定）

我直接给 WorkBuddy 下指令：

帮我搜集全网最完整的 SBTI 测试题库，整理成结构化数据，包含 15 道题目、4 个评分维度、27 种人格标签及解读，输出 JSON 格式。

手动整理要翻网页、核对版本，至少半小时。
AI 几秒就输出干净可用的数据，直接进入下一步。

第二步：生成前端代码

把整理好的素材交给 WorkBuddy，让它生成完整网页：

-
• HTML+CSS+JS 全套代码

-
• 答题、计分、维度计算逻辑

-
• 结果匹配、百分比展示、15 维度评分

-
• 纯前端运行，不需要服务器、不需要后端

AI 一次性写完，不用我从零敲代码。

第三步：制作 27 个 SVG 卡通头像

每种人格一个专属头像：

-
• 死者：灰色 X 眼躺平表情

-
• 吗喽：极简猴子线条头

-
• ATM‑er：绿色机器+硬币元素

-
• 其他 24 种人格逐一设计

全部用 SVG 手写，轻量化、加载快、风格统一。

第四步：加动效和细节打磨

粒子背景动画、渐变配色、按钮悬停、数字滚动、进度条动画……
最终效果：深色背景+紫色渐变主题+浮动粒子，打开就有科技感。

三、关键 BUG：保存图片不对

功能做完后，我加了“保存结果图片”方便用户发朋友圈。
结果出现一个很奇怪的问题：

页面显示正常，但保存出来的图片缺东西：

-
• 15 个维度评分 → 图片只显示 8 个

-
• 人格头像正常显示 → 保存后消失

-
• 人格解读卡片 → 图片里完全空白

我第一时间把问题丢给 WorkBuddy。 接下来所有定位、排查、修复，全是 AI 自己完成。

四、全程 AI 自动排查 BUG（真实踩坑实录）

我只把现象描述给 WorkBuddy：

页面显示正常，但保存图片时，15 个维度只显示 8 个，头像消失，解读卡片不显示。

第一步：WorkBuddy 自动定位问题

WorkBuddy 读完代码，立刻告诉我： 问题出在 Canvas 缩放后的像素单位混淆。

ctx.scale(2, 2);

缩放后，坐标计算没有统一单位，导致右侧内容直接超出画布被裁剪。

第二步：WorkBuddy 自动给出修复方案

AI 直接把错误代码改掉，给出正确写法：

const CWcss = CW / SCALE;
const PADcss = PAD / SCALE;
const colWcss = (CWcss - 2 * PADcss - 20) / 2;

统一使用 CSS 像素，问题瞬间解决。

第三步：AI 顺便排查出另外两个隐藏坑

-
1. 头像 SVG 嵌套重复
外层包了 <svg>，内层又来一层，导致保存时解析失败。
WorkBuddy 直接帮我删掉多余标签。

-
2. 解读卡片没写绘制逻辑
drawResultCard 函数漏写，AI 直接补全代码。

整个调试过程

我没有手动查代码、没有用任何工具扫描、没有自己分析原因。
全程只描述现象，WorkBuddy 自动读码 → 定位 → 修复 → 优化，一条龙搞定。

代码改完，我想直接部署上线。
我只对 WorkBuddy 说了一句：

帮我把这个项目部署上线。

接下来全部是 AI 自动完成：

-
2. 自动匹配项目结构

-
3. 自动提交、自动推送到仓库

-
4. 自动触发部署流程

全程一句话，AI 自己搞定。
